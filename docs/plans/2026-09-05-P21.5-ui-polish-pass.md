Two Minor Advisories for the Implementer

Spline is verified and 100% safe in 1.0.1. However, if visual QA feels Spline looks too much like a curve path rather than a closed polygon room, check if Pentagon or Hexagon exists in that node_modules export. If they do, either is an acceptable alternative; if not, keep Spline as pinned.

Native SVG for the Edge Pill (PlanSvg.svelte):

When teaching PlanSvg.svelte to render the rounded-rect timing badge behind text, use native SVG <rect rx="4"> and <text text-anchor="middle" dominant-baseline="central">. Avoid <foreignObject> here, as HTML foreignObjects in SVG canvases often suffer from subpixel blur and transform-matrix scaling bugs across Safari and Firefox.
