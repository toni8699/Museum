## 2. Design decisions

- **D1 — Selection is selection-only (Laws 2–4); `installSelectionScope` is fully retired.** `selection-actions` stops calling it; then remove the commands method, the facade delegate, its `EditorSelectionActionsHost` members, the `controller-hosts.ts` wiring, and `EditorSelectionPreviewScopeRequest` if it becomes unused (final unused-type cleanup gate in §8). Explicit `previewEdge` / `previewCamera` (playhead 0, paused) are the scope-entry commands. Do **not** repurpose `installSelectionScope` — its Sequence-progress handoff is P11 semantics, not P12.
- **D2 — Sequenced-node click in Sequence scope: pure Sequence seek + pause, via an explicit selection→timeline bridge.** New non-selecting primitive (one authority for all Sequence-scope seeks):

  ```ts
  // camera-timeline-controller
  seekSequencePreview(progress: number): boolean
  // validate Sequence scope + resolved progress/boundary
  // → requestTransportPause()
  // → setCameraPreviewPlayhead(progress, sequenceRunId)  // syncs cameraTimelinePlayhead (pinned: editor-store-camera.test.ts:1999-2000)
  // → NO selection mutation, NO Camera/Edge install
  ```

  **Bridge (selection-actions must not import the timeline controller):** add `seekSequencePreviewForNode(nodeId: string): boolean` (or a progress-accepting variant) to `EditorSelectionActionsHost`, wired through `controller-hosts.ts` → `cameraTimelineController`. `selectNavigationNode(C)`: commit canonical selection → if active scope `sequence` && C sequenced && evaluable boundary → `seekSequencePreviewForNode(C)`.

  **Boundary disambiguation:** generic viewport/tree clicks use the deterministic nearest boundary to the current playhead (matching `stepCameraTimeline` cue selection); only an explicit timeline node-dot click with a `boundaryIndex` targets the exact occurrence (loop nodes can appear twice via the closing edge). **No double seek:** the timeline-dot path selects with automatic seek suppressed, then performs **exactly one** exact-boundary seek (never nearest-then-exact).

  **Re-click semantics (no-op cannot short-circuit transport):** an already-selected sequenced node in Sequence scope still seeks + pauses whenever transport is `playing` or the current playhead differs from the node's resolved boundary. It is a no-op **only** when already paused at that exact resolved boundary. Selection equality must not block the §4 transport behavior.

  **Focus suppression:** the Sequence-scope node click does **not** issue `focusNavigationNode(id)` framing — the Sequence evaluator owns the camera response to that click (otherwise the observer receives two camera intents).

  Post-gap/malformed → `lastEvaluableBoundary` (D7) + existing `Gap at Node N` diagnostic. Outside Sequence scope → selection only.
- **D3 — Preview Camera is Unsequenced-only.** `commands.previewCamera` and every entry point reject sequenced nodes (`guidedTourNodeIds` membership). Sequenced node context menus hide/disable `Preview Camera` with a tooltip pointing to Sequence-scope static inspection. Supersedes the P11.1 "Preview Camera works for every camera" grammar (§3).
- **D4 — `requestTransportPause()` + strict late-pause order.** New seam, modeled on `requestAuthoringPause` minus the visitor refusal: `if (cameraPreview && transport !== 'paused') pauseCameraPreview(); return true;` — pauses POV or Observer. **Pinned order on every seek path** (split the current `#canSeekCameraTimeline`): prohibited-state guard (interaction/transaction/pending) **early** → validate input / resolve timeline / resolve cue or boundary → detect true no-op → `requestTransportPause()` → write playhead. An invalid scrub, stale node, missing timeline, or no-op target must not pause playback as a side effect. `requestAuthoringPause`/`requestFramingPause` remain the document/framing-write gates (§4 seam split).
- **D5 — Sequence scrub uses the same primitive; no pose-helper reuse.** `seekCameraTimeline` in Sequence scope: resolve global progress → `requestTransportPause` → `setCameraPreviewPlayhead(progress, sequenceRunId)` → preserve canonical selection → preserve Sequence scope. **No `selectCameraConnectionDirection`, no `showCameraTimelineConnectionPose`** (both install scopes). One primitive serves ruler scrub, sequenced-node seek, and step.
- **D6 — Direction choices: reuse, don't build.** Acceptance-pin `getCameraEdgePreviewChoices` (Sequence-adjacent single predecessor→successor; non-adjacent both directions; never storage-order fallback) and re-audit `EditorCameraEdgePreviewActions` mounts per §3. No new chooser component in S2; S3 mounts the same choices inside the Scope pill.
- **D7 — Partial-route authority + evaluable-prefix Sequence lifecycle.** §4's "seeks to last evaluable boundary" has no data source today (`{ timeline, diagnostic }` returns `timeline: null` on gap), and the gap is thrown mid-walk by `walkFlowChain` (prefix lost). **The traversal authority is `camera-route.ts` — extend it there:**

  ```ts
  // camera-route.ts — canonical partial-route result (exact shape TBD)
  type FlowRouteResolution =
    | { route: ResolvedCameraRoute; gap: null }
    | { route: ResolvedCameraRoute | null; gap: { fromNodeId: string; toNodeId: string } };
  ```

  `walkFlowChain` returns the evaluable prefix + gap instead of throwing away the partial path. `editor-camera-timeline.ts` **only projects** that canonical result into timeline + boundary data — never re-walks `nextNodeId`/connection adjacency. The existing `{ timeline, diagnostic }` boundary stays, widened with the derived `lastEvaluableBoundary` (`EditorCameraTimelineNodeBoundary | null`), which belongs to the evaluable prefix.

  **Lifecycle consequence (must be named):** with a non-empty evaluable prefix, Sequence scope may **remain/install paused** — timeline = evaluable prefix, diagnostic = `gap`, `lastEvaluableBoundary` from that prefix. With no evaluable motion/prefix → no playable Sequence (existing idle fallback). Otherwise the post-gap acceptance test has no reachable runtime state.
- **D8 — Scrub/step availability and step as pure transport.** `scrubDisabled` / `edgeScrubDisabled` / step guards: **do not disable merely because `transport === 'playing'` or POV/visitor** — a playing scrub pauses first via the seam. Keep disabling for active interaction/transaction, missing timeline, zero duration, and invalid targets. Edge scrub moves behind `seekEdgePreview(progress)` → `requestTransportPause` → `setCameraPreviewPlayhead(progress, runId)`; the Ruler stops writing the playhead directly. **Step is pure transport for both temporal scopes and both modes** (Law 5): resolve next/previous cue → validate → `requestTransportPause()` → seek the active scope (Sequence via `seekSequencePreview`, Edge via `seekEdgePreview`) → selection unchanged → scope unchanged. Reconcile the two existing stepping engines at least to this contract; full engine consolidation is recommended but **deferred** out of S2.
- **D9 — Relic isolation.** P12.2 must not alter frozen `/museum/editor` behavior. Every shared store/component S2 touches is audited for `isRelic` disposition; prefer proving shared changes are behavior-neutral for the relic over creating a second relic-specific implementation. Add relic regression coverage (selection, scrub/step, Preview Camera/Edge, timeline interaction).

## 5. Test matrix

- sequenced node click, Sequence scope → seeks boundary, `paused`, playhead at boundary, **no scope change**, **no focus framing**;
- **re-click an already-selected sequenced node while playing / at a different playhead → still seeks + pauses; no-op only when already paused at that boundary**;
- timeline node-dot click → **exactly one** exact-boundary seek (no nearest-then-exact), selection committed once;
- sequenced node click, Edge/Camera scope → selection only; scope/playhead/transport unchanged;
- post-gap node click → `Sequence` scope remains/installs **paused** on the evaluable prefix, `Gap at Node N` diagnostic, `lastEvaluableBoundary` seekable; no-prefix case → no playable Sequence;
- loop node (closing edge) → nearest-boundary rule on generic click; exact occurrence on `boundaryIndex` click;
- edge click, all scopes → selection only;
- unsequenced node click → selection only; explicit Preview Camera installs Camera scope;
- sequenced node → Preview Camera unavailable; static inspection via `Sequence → boundary → paused`;
- `requestTransportPause()`: seek/scrub/step pause a playing preview in **POV and Observer** (mode-independent; supersedes P11.2 refusal pins);
- scrub/step **enabled while playing** (pause-then-seek); still disabled for interaction/transaction/zero-duration/missing timeline;
- invalid scrub (non-finite, stale node, missing timeline, no-op target) does **not** pause (D4 order pin);
- **step: Sequence + playing + POV → pause + seek, selection unchanged, Sequence unchanged; Edge + playing + POV → pause + edge-local cue seek, selection unchanged, Edge unchanged** (Law 5 both scopes);
- Sequence scrub leaves scope and selection unchanged (Law 2 pin);
- Sequence-adjacent Preview Edge → single predecessor→successor action; non-adjacent → explicit two-direction choice, never storage-order fallback;
- `installSelectionScope` retired — no callers and no unused host/type remnants (source assertion + unused-type gate);
- **relic regression**: selection, scrub/step, Preview Camera/Edge, timeline interaction behave as before under `isRelic`;
- migration: `p11-s1` selection-install assertions → selection-only assertions; `p8-s2` D1-family pins reconciled per §9.

## 7. Risks

- **Seek-scope reversal is the largest semantic change** (P11.1 shipped scrub-into-edge-scope). Isolate behind the §4 matrix tests; land D5 (scrub) separately from D2 (node click).
- **Recursion/double-seek traps:** never call `selectCameraTimelineNode` from `selectNavigationNode`; the timeline-dot path must select with auto-seek suppressed and seek exactly once. The pure `seekSequencePreview` is the only seek path.
- **Pose helpers install scopes** — `showCameraTimelineNodePose`/`showCameraTimelineConnectionPose` must not appear in any S2 seek path.
- **Partial-route authority** — evaluable-prefix derivation lives in `camera-route.ts`; timeline/UI must not re-walk `nextNodeId`/connections. Name the evaluable-prefix Sequence lifecycle (D7) or the post-gap acceptance test has no runtime state.
- **Scrub-while-playing is a contract requirement, not an affordance** — removing the disable must land with the late pause seam (D8/D4), or scrub-while-playing seeks without pausing.
- **Re-click no-op** must not block §4 transport behavior — selection equality short-circuits nothing (D2).
- **Relic drift** — shared edits must be `isRelic`-dispositioned and behavior-neutral; regression coverage is required (D9).
- `installSelectionScope` callers are exactly the two `selection-actions` sites + the facade delegate + host wiring — grep before removal.
