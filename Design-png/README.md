# Canonical UI sketches

**Status:** active visual registry — reconciled 2026-08-23 by P9; Camera
sidebar and Scene 3D XYZ-gizmo authority corrected 2026-08-23.  
**Authority:** source/tests → shell/workspace specs → `Design-specs.md` → these
compositions. Git history owns superseded concepts. Where an older composition
disagrees on Camera neighbor presentation, the sidebar authority note below
wins. Where it omits a transform axis, the Scene 3D gizmo amendment below
wins. Older images remain registered for their named primary states.

## Locked shell

- App bar: Museum editor + project · `Scene | Camera` · shared `Plan | 3D` ·
  Saved/Unsaved · Undo/Redo · domain preview action · Project. No standalone
  Save or Settings.
- Blue `#2F8CFF` is the sole active/selection accent.
- Scene Plan always shows one consistently-positioned `Layout | Staging` local
  control. Camera Plan never shows it.
- Camera sidebar: Environment · Sequence Inspector · Unsequenced · Connections.
  Environment is read-only; P1.9 neighbors appear only in per-camera flat
  accordions, ordered Sequence neighbors are omitted, reorder is drag-only,
  and topology labels are undirected.
- Camera Plan tools: Select · Add Camera · Connect · View plus Grid/Snap. No
  Measure and no editable Y/orientation.
- Camera 3D tools: Select · Move · Rotate · Add Camera · Path · Frame · View.
- Preview copy: Preview Camera · Preview Edge · Preview Sequence. Directional
  arrows belong only to preview/playback, never topology lists.
- Camera timeline: `288px` default / `48px` collapsed; Camera Path · Shots · FOV
  · Look At · Roll display lanes over the current two-lane backing model.
