## 2. Design decisions

- **D1 — One shell, truthful Edge-local lane projection (Law 1 + §5, closes `L248`).** `EditorCameraTimelinePanel` stays the one shell. The Edge branch currently `Dots hidden` (`:80-91`) is widened to render the same 5 lanes with **Edge-local** presentation data; no second `EditorCameraEdgeTimeline.svelte`, no second store.

  ```ts
  // Pure Edge-local projection — reuse S1 directed-edge resolver, no global mapping
  // editor-camera-timeline.ts: createEdgeLocalTimeline is the duration/motion source
  // No: cameraTimelineProgressAtEdgeProgress(global, …) under Edge ruler
  ```

   Per-lane backing + quiet criteria (derived from existing types, no new entities). **View-key progress is Edge arc-length** (`connection.viewTracks[dir][i].progress` in `[0,1]` edge domain), not linear ruler time — easing requires `cameraMotionProgressAtEdgeProgress` before positioning (closes `L51`):

  | Lane | Sequence scope | Edge scope | Source / mapping |
  |---|---|---|---|
  | Camera Path | full `timeline.edges` spans | **Edge Camera Path renders one full-width connection timing span from `0` to `edgeTimeline.durationSeconds`** (`edgeTimeline.motion:530` `durationSeconds`), independent of the number of route `positionParts` (`camera-route.ts:79` `positionParts: readonly CameraPositionPathPart[]` may be `>1` per connection) | `edgeTimeline.durationSeconds` + `edgeTimeline.motion` (no `motion.positionParts`) |
  | Shots | `nodeBoundaries` / hold segments | **Quiet** — single connection has no independent shot data (never synthesize) | — |
  | FOV | truthful eval `viewTrack.keyframes[].fov` mapped via global progress | truthful eval `edgeTimeline.motion.positionEdgeSpans[0].viewTrack.keyframes[].fov` mapped via `motion` with `cameraMotionProgressAtEdgeProgress(motion, 0, key.progress)` → `timeProgress` → `left = percent(timeProgress)`, time = `timeProgress * edgeDurationSeconds` | `motion` + `cameraMotionProgressAtEdgeProgress:27` |
  | Look At | same via `cameraTarget` | same via `motion` `cameraTarget` with same `cameraMotionProgressAtEdgeProgress` mapping | `motion` + same helper |
  | Roll | `Quiet (unless authored)` | `Quiet (unless authored)` | `motion` (always 0 today) |

  Ruler/timecode `0s → edgeDurationSeconds`, every lane element uses same Edge-local mapping. Any element that cannot truthfully project into `[0, edgeDuration]` stays quiet. Never use linear `key.progress * durationSeconds` — easing would lie. This supersedes `P11.3 Edge mini-shell` hidden-lanes only (`§9` retain invariant).

- **D2 — Flip atomic transition, reset to 0 for non-relic (closes `L184`, supersedes `P11.4 1-e`).** Frozen `§3:184` specifies result `0`; this brief pins the transition. Relic branch is D6:
