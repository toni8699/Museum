## Review amendment pass (2026-08-20)

Six review findings plus a performance bound, folded in:

1. **F1 — view signal to the timeline lane.** The timeline mounts for the
   Camera domain in both Plan and 3D, but view state never reaches the timeline
   children. Thread `viewMode: 'plan' | '3d' = '3d'` through
   `EditorCameraTimelineFrame` → `EditorCameraTimelinePanel` →
   `EditorCameraTimelineDots`. `EditorApp` passes
   `viewMode={viewState.activeView}`; the relic mount (`MuseumEditorApp`) omits
   the prop and stays `'3d'`. The envelope band/handles render only when
   `viewMode === '3d'`; Camera Plan keeps key markers only.
2. **F2 — reconciliation callback.** `EditorViewKeyframeController` exposes
   `afterDocumentReplaced()`, registered via
   `documentStore.addAfterReplaceListener(...)` beside the existing
   preview/selection listeners. It re-derives policy from the live document on
   commit, cancel, undo, redo, import, and reset.
3. **F3 — public guard status.** `CameraMotion.edgeViews` is public but its
   element/guard types are private. Add one narrow, exported, readonly
   guard-status type/accessor in `camera-motion.ts` (e.g.
   `CameraFramingGuardStatus = { limitsAngularRate: boolean; hasBypass: boolean;
   hasStandoff: boolean }`) derived from the private compiled guard. This is the
   single permitted `camera-motion.ts` change: type/API-only, no sampler or
   runtime behavior change, asserted by a before/after byte-identical sampling
   test.
4. **F4 — drag ordering.** Required order: select direction → mark manual →
   begin transaction → install drag session. The initial direction-select cannot
   self-cancel (no drag session exists yet); later selection/direction changes do
   cancel.
5. **F5 — preset wording.** A changed preset creates one history entry; an equal
   preset creates none but still marks policy manual.
6. **F6 — Centered preset contract.** The Centered button writes the exact
   `{0.25, 0.5, 1, 1}`, marks manual, and may contract an auto-expanded seed —
   even if a key then lies inside the enter ramp instead of the plateau.
   Intended; pinned by test.
7. **Performance bound — comfort diagnostics.** Diagnose the active
   connection/direction only; cache route/motion in `$derived`; cap sampling at
   96 samples per ramp; reuse one `CameraMotionSample`; do not scan every
   timeline edge during a drag.

## Outcome

Camera → 3D becomes the framing-authoring surface for each connection direction.
Designers choose when authored focus takes over, choose familiar lens presets,
inspect the resulting envelope and comfort warnings, and edit raw envelope
bounds when needed. Camera Plan remains framing-free.

Selecting a Camera 3D connection also exposes the same per-direction duration,
effective time, path length, and derived speed already shipped in Camera Plan.
Both surfaces read one shared timing model and write through
`setConnectionTiming`; path or timing math is never duplicated in UI code.

## Out of scope

- No arrival/departure pose, endpoint override, custom weight curve, second FOV
  envelope, direct rotation-speed control, or persisted auto/manual flag.
- No Camera Plan framing controls, view cones, breakpoint markers, or envelope
  handles. Camera Plan keeps only timing authoring from P1.5.
- No path/topology, motion sampler, schema, import/export, visitor, relic,
  Scene/Layout workspace, P2 staging, or P3 visual-overhaul changes.
- No automatic editing of camera position, look target, or connection duration
  to silence a diagnostic. Warnings explain; designer remains author.

## Product constants and pure authoring model

Add one editor-only pure module, suggested
`editor-camera-framing-authoring.ts`. It owns named presets, lens conversion,
envelope mirroring, handle clamping, and diagnostics. It imports shared motion
APIs but no Svelte/store/Three scene objects.

### Focus-timing presets

Preset values use normalized **edge-local distance progress**, not spline
parameter or wall-clock percentage:

```ts
const CAMERA_FOCUS_TIMING_PRESETS = {
  early:    { enterStart: 0.05, enterEnd: 0.20, exitStart: 1, exitEnd: 1 },
  centered: { enterStart: 0.25, enterEnd: 0.50, exitStart: 1, exitEnd: 1 },
  full:     { enterStart: 0,    enterEnd: 0,    exitStart: 1, exitEnd: 1 }
} as const;
```

- Labels: **Early**, **Centered**, **Full Move**.
- `centered` is first-key seed. Pass it to
  `createAutoManagedFramingEnvelope`; reducer expands it so first key reaches
  full authored influence and keeps `exitEnd = 1`.
- **F5:** a preset click writes the exact preset and marks the direction manual.
  A changed preset creates one history entry; a preset equal to the current
  envelope creates none but still marks session policy manual.
- **F6:** the Centered *preset* writes the exact `{0.25, 0.5, 1, 1}` and may
  contract an auto-expanded seed (a key can move from plateau into the enter
  ramp). This is intended; pin it with a test. The centered *seed* passed to
  `createAutoManagedFramingEnvelope` is distinct and expands to contain the key.
- `Full Move` is the discoverable `w = 1` escape hatch.
- Primary presets never resume automatic facing before arrival. Advanced
  `exitStart` / `exitEnd` controls remain sole path to `exitEnd < 1`.

### Lens presets and copy

Expose **24 mm Wide**, **50 mm Standard**, and **85 mm Tight** beside existing
degree field. Convert full-frame focal length to vertical FOV with fixed 24 mm
sensor height:

```text
verticalFovDegrees = 2 × atan(24 / (2 × focalLengthMm)) × 180 / π
24 mm = 53.130° · 50 mm = 26.991° · 85 mm = 16.071°
```

All values fit `MUSEUM_CAMERA_FOV`. Presets call existing node/key FOV commit
methods, so one click = one history entry and forward-key reverse seeding stays
centralized. Keep degree field available for arbitrary lenses. UI copy must say:
**“Larger FOV is wider / zoomed out. Smaller FOV is tighter / zoomed in.”**
Never use “expand” for a tighter lens.

Lens presets appear for node and view-breakpoint FOV. Envelope affects keyframe
FOV and target together; there is no FOV-only timing control.

### Comfort policy

```ts
const CAMERA_FRAMING_AUTHORING_COMFORT = {
  minFovRampSeconds: 0.6,
  maxFovRateDegreesPerSecond: 30,
  diagnosticSamplesPerRamp: 96
} as const;
```

- Compute ramp seconds through `cameraMotionProgressAtEdgeProgress(...) ×
  motion.durationSeconds`; never use `progress × duration` or UI-local easing.
- Non-zero envelope-handle drags clamp to at least `0.6 s` when the oriented
  track changes FOV. Holding `Alt` bypasses clamp for deliberate dolly zoom.
  Raw numeric fields are also deliberate overrides: accept valid ordered values
  and show diagnostic instead of silently changing them.
- Zero-width ramps remain legal intentional steps. Never expand or reject them;
  label them **Step lens change** in diagnostics.
- Sample exact public `CameraMotion` across each ramp to report peak FOV rate.
  Above `30°/s`, show **Rapid lens change** with measured rate and ramp time.
- **Performance bound:** diagnose the active connection/direction only. Cache
  the resolved route/motion in `$derived`, cap sampling at
  `diagnosticSamplesPerRamp` per ramp, reuse one `CameraMotionSample`, and do
  not scan every timeline edge during a drag.
- Read the compiled oriented edge guard state through the **F3** public
  guard-status accessor. `limitsAngularRate` or a non-null bypass shows
  **Parallax turn softened**; a guard without those flags shows **Target passes
  close to camera path**. Diagnostics are editor hints, not new runtime policy
  or duplicated thresholds.

## Directional envelope policy state

`framingEnvelope` remains serialized per direction; management remains
session-only. `EditorViewKeyframeController` owns a private map keyed by
`` `${connectionId}:${direction}` `` with current
`CameraFramingEnvelopePolicyState`.

Rules:

1. Existing/imported envelopes are first observed as `manual`. Missing
   envelopes have no policy entry.
2. First directly or indirectly created directional key uses centered seed and
   stores `auto` state in the same document transaction as the key.
3. Later add, progress drag/commit, and delete operations pass current key
   progresses through `updateFramingEnvelopeForKeyProgresses` inside their
   existing transaction. Auto expands only; manual never moves.
4. Handle pointer-down or raw/preset edit calls
   `markFramingEnvelopeManual` from gesture intent, even if numbers finish
   unchanged. No numeric document change means no history entry.
5. Before each document replacement, controller has already staged expected
   policy value. **F2:** the controller exposes `afterDocumentReplaced()`,
   registered on `documentStore.addAfterReplaceListener(...)` and invoked after
   every successful `replace()` (commit, undo, redo, import, reset). After
   replace, keep management only when the live envelope equals the staged
   envelope. Unknown/different values—including import or undo—reconcile
   conservatively to `manual`; missing directions are pruned. No history stack
   or schema field is added for management.
6. Handle drag snapshots document transaction plus policy state. Escape,
   pointer cancel, lost capture, window blur, selection change, direction
   change, or unmount restores both. Pointer-up commits one history entry.
7. Deleting last key keeps persisted envelope, matching P1.4. Explicit envelope
   removal is not part of P1.6.

Forward-derived reverse behavior:

- When first forward key seeds an empty reverse track, also create mirrored
  reverse envelope in same transaction:
  `{1-exitEnd, 1-exitStart, 1-enterEnd, 1-enterStart}`. Both states start auto.
- Later forward sync mirrors envelope only while reverse policy is auto. A
  manual reverse envelope is preserved.
- Explicit Copy Forward/Reverse mirrors source keys and source envelope into
  destination, then marks destination manual. Missing source envelope removes
  destination envelope only as part of this explicit copy command.

## UI composition

### Camera 3D Inspector

Extract small shared components rather than growing duplicate blocks:

- `EditorCameraConnectionTiming.svelte`: direction switch, path length,
  effective duration, authored duration, speed, and Use automatic.
- `EditorCameraFramingControls.svelte`: focus presets, current envelope summary,
  diagnostics, Full Move, and Advanced disclosure.
- Extend `EditorCameraFovField.svelte` with optional preset buttons and exact
  wide/tight explanatory copy; current degree/range behavior remains.

Mount timing + framing controls for Camera 3D connection selection. Mount
framing controls for view-breakpoint selection using that key's direction, so
focus timing stays reachable while editing a key. Node selection gets lens
presets only. Direction buttons call
`selectCameraConnectionDirection(connection.id, direction)` and therefore keep
timeline, preview, Plan/3D selection memory, and Inspector on one direction.

Advanced disclosure contains four percentage fields in canonical order:
`Enter start`, `Full focus`, `Resume automatic`, `Automatic by`. Show an inline
mini legend: automatic → blend → authored → blend → automatic. Ordered invalid
drafts do not commit and restore last valid value. `exitEnd = 1` reads **Authored
through arrival**.

Empty/legacy states stay explicit:

- no directional keys: **Automatic framing — add a view breakpoint to shape
  focus**; presets and Advanced are disabled and write no envelope;
- keys with no envelope: **Legacy Full Move**; playback remains absent-field
  `w = 1` until an explicit preset materializes an envelope; and
- keys with envelope: show preset match when exact, otherwise **Custom**.

### Camera Framing timeline lane

**F1:** `EditorCameraTimelineFrame`, `EditorCameraTimelinePanel`, and
`EditorCameraTimelineDots` each gain `viewMode: 'plan' | '3d' = '3d'`.
`EditorApp` passes `viewMode={viewState.activeView}`; the relic mount
(`MuseumEditorApp`) omits the prop and stays `'3d'`.

For each guided edge, resolve same oriented direction already used by visible
key markers. Draw envelope influence band only when `viewMode === '3d'` and
that direction has keys and an envelope. Map all four bounds through
`cameraTimelineProgressAtEdgeProgress`; do not place with raw global percentages.

- Collapsed mode: band only, with automatic/blend/authored visual regions.
- Advanced open for active connection: show four keyboard-focusable handles.
- Handle hit target may exceed visible marker, but ordering cannot invert.
- **F4:** pointer-down order is fixed — (1) `selectCameraConnectionDirection`
  (the initial select cannot self-cancel: no drag session exists yet), (2)
  `markFramingEnvelopeManual`, (3) `beginDocumentTransaction`, (4) install the
  drag session and capture pointer. Pointer move previews exact shared motion;
  pointer-up commits once.
- Later selection changes (other than the initial direction-select) and
  direction changes cancel the drag.
- Arrow keys move selected handle by `0.01`; Shift+Arrow by `0.05`; Home/End
  move to nearest legal neighbor/endpoint. One keyboard adjustment = one entry.
- Escape cancellation runs capture-phase before global shortcut cascade.
- Plan ↔ 3D unmount cancels active handle drag before swapping surface. Camera
  selection and direction otherwise survive unchanged. Camera Plan shows key
  markers only — no band, no handles.

## Connection duration convergence

Move `camera-plan/camera-plan-timing.ts` to an editor-shared location and update
Camera Plan imports. Shared timing component must:

- construct exact directional route/motion through existing APIs;
- show authored vs automatic effective duration, exact path length, and finite
  derived speed;
- write finite positive `durationSeconds` through `setConnectionTiming`;
- preserve directional easing when duration changes or is removed; and
- pass `null` only when no timing fields remain.

Changing duration immediately recomputes envelope ramp seconds and diagnostics
because both derive from same motion. Authored envelope bounds remain unchanged.
Camera Plan and Camera 3D values must match for same connection/direction.

## Manual acceptance

1. In Camera 3D, select a connection, choose forward, pause Director mid-edge,
   add first view key. Centered envelope appears; one Undo removes key plus both
   auto-created directional envelopes/derived reverse key.
2. Try Early, Centered, Full Move. Preview begins authored focus at documented
   distances and arrives at canonical destination pose.
3. Open Advanced, drag each handle, cancel once with Escape, then commit once.
   Undo count changes only for committed gesture. Plan view shows no framing UI.
4. Apply 24/50/85 mm to node and breakpoint. Degrees/copy read wide→tight
   correctly; preview uses same envelope for target and FOV.
5. Force fast ramp. Normal drag respects 0.6 s; Alt and raw numeric edit keep
   deliberate faster value and show rapid-lens diagnostic. Zero-width step
   stays authorable.
6. Aim target through/near path and create late return-to-auto. Relevant
   parallax/proximity hint appears while preview remains finite and guarded.
7. Edit forward/reverse duration in Camera 3D, switch to Camera Plan, and verify
   identical duration/length/speed. Use automatic preserves easing.
8. Start handle drag, then press Escape or switch Plan/3D. Draft rolls back;
   selection/direction survives; no stuck transaction or shortcut cascade.
